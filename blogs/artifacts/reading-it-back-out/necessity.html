H4 · necessity vs specificity
Remove the direction, lose the disposition

Project the identity direction out of the residual stream during the forward pass, then measure how far each arm's own disposition (Dself) collapses. Removing an arm's own anchor collapses it about 97%, necessity holds. But removing a foreign arm's anchor still collapses it 72–79%, so the arms sit in a largely shared religious subspace with only a thin religion-specific component on top. That gap is specificity, and it is only partial.

Necessity holds, specificity is partial. Every arm's own direction is necessary, ablating it removes almost all of the implanted disposition. But a foreign arm's direction ablates most of it too, so the traditions share a common religiosity subspace and only differ by a thin arm-specific layer. This is exactly why the arms resist and absorb each other's steering.
